# 文档总索引

> 仓库分两层：**framework/** 是不随故事变化的游戏框架，**story/** 是生长在框架上的世界观与内容。
>
> **目录约定**：每个子游戏一个独立子目录 `docs/subgames/<子游戏名>/`，文档按需更新；主线战役书归入 `story/`。
