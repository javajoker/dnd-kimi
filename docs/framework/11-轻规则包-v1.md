# 轻规则包 v1（light v1）

> 版本：v1.0（定稿，对应 P0.8 首个轻规则包细则）
> 关联文档：`05-规则系统框架.md` §3/§8（六要素与方向）、`../story/02-战役书-烬港残页.md`（首个绑定战役，推荐等级 1~4）
> 范围：轻规则包六要素的完整数值定义。目标：5 分钟讲清规则，单手操作友好，检定演出突出；为后续标准档预留扩展位。

---

## 1. 属性模型

- **三维属性**：力（Might）/ 敏（Finesse）/ 智（Wits），取值 **-1 ~ +3**；
- 创建分配：**+2 / +1 / 0** 三档各一（同伴由内容包预定义）；
- **HP = 10 + 2×等级 + 力修正**；
- 扩展位预留：数据结构按"属性表"而非三个硬编码字段实现，标准档升 6 维时由映射表折叠（05 文档 §5）。

## 2. 技能表（三维衍生）

| 技能 | 属性 | 用途示例（campaign01 落位） |
|---|---|---|
| 运动 athletics | 力 | 攀爬、破门 |
| 威吓 intimidate | 力 | 逼供、喝退 |
| 潜行 stealth | 敏 | N2U-1 黑羽集会 |
| 巧手 thievery | 敏 | 撬锁、陷阱 |
| 感知 perception | 智 | N0-2 消失的码头名 |
| 调查 investigation | 智 | N1-2 褪色现场、N2L-1 独自调查 |
| 历史 history | 智 | N2S-1 档案馆试炼 |
| 交涉 persuasion | 智 | N2G-1 残篇拍卖 |
| 安抚 soothe | 智 | R2 空教室 |

- 检定边可声明 `a_or_b` 双技能（如 `history_or_perception`）：取两者修正较高者；
- 技能不设独立等级，修正 = 属性修正 + 熟练（+2，若该技能熟练）。角色创建选 2 个熟练技能。

## 3. 检定公式

```
d20 + 属性修正 (+ 熟练 +2) (+ 道具修正) vs DC
难度三档：易 DC 8 / 中 DC 12 / 难 DC 16
```

- 输出恒为**成功/失败双分支**（D20 最小核，05 文档 §2）；
- 自然 20 = 大成功（成功 + 内容包可附加成效果），自然 1 = 大失败（失败 + 可附加代价）；两者触发演出加档（09 文档 §6）；
- 道具修正（`check_mod` 身份）单次 ≤ ±4（10 文档 §1）。

## 4. 行动经济（三段式）

每回合：**移动（≤6 格）+ 动作 ×1 + 附赠动作 ×1**，顺序自定。

- 动作：攻击 / 技能 / 使用物品 / 救助倒地队友；
- 附赠：喝药、切换武器、短距位移技能等（技能卡标注）；
- 反应动作**不属于轻规则**（标准档引入）。

## 5. 战斗回合结构

- 先攻 = d20 + 敏修正，降序轮转，平局玩家优先；
- 攻击检定：d20 + 属性修正 vs 目标 AC（AC = 10 + 敏修正 + 护甲值）；
- 伤害 = 武器骰 + 属性修正（武器骰表见 §8）；
- 胜负条件：一方全灭 / 撤退边 / 遭遇定义的目标达成（护送、存活 N 回合等）；
- 同屏单位 ≤8（竖屏约束，校验器 V8）。

## 6. 成长曲线（1~4 级，对齐 campaign01）

| 等级 | 升级所需经验 | 获得 |
|---|---|---|
| 1 → 2 | 300 | +HP；技能槽 +1 |
| 2 → 3 | 700 | +HP；属性点 +1（任一，≤+3 封顶） |
| 3 → 4 | 1200 | +HP；技能槽 +1；熟练技能 +1 |

经验来源：遭遇结算 + 失败路补偿（失败也有戏，经验不打折原则：失败路经验 ≥ 成功路的 80%）。

## 7. 死亡与失败

- HP=0 → **倒地**：进入死亡豁免，每回合 d20 ≥ 10 记一胜，<10 记一负，**三局两胜**——先三胜稳住（1 HP），先三负死亡；
- 队友可用动作救助（急救，d20+智 vs DC 8，成功即稳）；
- 死亡豁免是框架恒定**关键判定**（全屏演出，09 文档 §6）；
- 团灭 = 遭遇失败 → 走该遭遇的失败路分支（白皮书铁律：失败即分支，非读档）。

## 8. 武器骰与技能次数制

| 武器类别 | 伤害骰 | 例 |
|---|---|---|
| 轻型 | d4 | 短刃 |
| 单手 | d6 | 港卫佩剑 |
| 重型 | d8 | 船钩斧 |
| 法术式 | d6（智） | 墨术飞矢 |

- 无法术位；**技能次数制**：每个主动技能每场遭遇 N 次（标注在技能卡，通常 1~3 次），休整态恢复；
- 职业以**技能组合包**呈现（首发三包：港卫 / 拾荒客 / 墨徒——玩家感知风格而非条文，05 文档 §8）。

## 9. 难度标定与投放节奏（供内容作者）

| 战役阶段 | 推荐遭遇难度 | 检定难度配比（易/中/难） |
|---|---|---|
| 序章教学 | 易 | 全易 |
| 幕一 | 易~中 | 3/5/2 |
| 幕二 | 中 | 2/5/3 |
| 幕三 | 中~难 | 1/4/5 |
| 终章 | 难 | 关键判定集中于演出，不以难度卡人 |

预期通过率：中档检定对+2 属性+熟练 ≈ 65%（d20+4 vs 12）——"大多数掷骰有悬念，失败有戏看"的目标区间。

## 10. 与框架的接口确认

- 事件流格式、状态板读写路径遵守 D20 最小核三条不可变项；
- 规则包 ID：`light`，版本 `1`；campaign01 manifest 已按此声明绑定；
- 本包废弃策略、冻结机制、跨包属性映射表规范见 05 文档 §7/§9（映射表在首个跨规则包战役出现时冻结）。
