## 1. 手势词表（判定参数为框架恒定值）

| 手势 | 判定参数 | 语义分类 | 典型用途 |
|---|---|---|---|
| 单点 tap | 按下-抬起 <300ms，位移 <10pt | 选择 / 确认 | 选项、按钮、目标格、目标单位 |
| 双指点击 two-finger tap | 双触点同帧按下，持续 <300ms，各点位移 <10pt，两触点间距变化 <15pt（与捏合区分） | 快捷确认 | 结束回合、普通检定一键快掷 |
| 长按 long-press | 按住 ≥400ms，位移 <10pt | 查看 / 跳过 | 单位与道具详情卡、跳过演出 |
| 拖动 drag | 位移 >10pt 后抬手 | 位移 | 战场移动单位、滚动列表、拖镜头 |
| 拖动轨迹 path | 拖动经过 ≥2 个语义目标点 | 施法 / 瞄准 | 技能释放：起点=施法者，轨迹=弹道，终点=目标 |
| 横滑 swipe | 水平位移 >60pt，垂直 <30pt | 切换 | 操作台四 Tab、已过房间回看条 |
| 双指捏合 pinch | 双触点间距变化 >20% | 缩放 | 战场：跟随镜头 ↔ 全局俯瞰 |
| 双指拖动 two-finger drag | 双触点同向位移 | 平移 | 缩放后的战场平移 |

铁律：**一切手势都有按钮替代路径**——手势是效率层，不是唯一通道（无障碍与新手保护）。每个手势指令在界面上必有等价的可点控件。

## 2. 场景映射

### 2.1 遭遇 · 横屏空间形态

| 手势 | 作用 |
|---|---|
| 单点 | 选单位 / 目标格 / 左栏动作 |
| 拖动（单位起） | 移动单位到可达格（消耗移动段，拖动中显示可达范围与落点预览） |
| 拖动轨迹（单位→敌） | 释放指向性技能（轨迹即弹道预览，松手确认；抬手落空位=取消） |
| 双指点击（战场任意处） | 结束回合 |
| 长按（单位） | 信息卡半屏弹层（HP/AC/伤害骰/状态） |
| 双指捏合 | 战术格缩放（8×5 全景 ↔ 局部跟随） |
| 双指拖动 | 缩放后平移镜头 |

### 2.2 遭遇 · 竖屏时间形态

| 手势 | 作用 |
|---|---|
| 单点 | 选项 / 操作台按钮 / 可交互物高亮 |
| 横滑（操作台） | 四 Tab 切换（行动/骰子/日志/角色） |
| 拖动（己方单位，纵向） | 竖向战场调整站位（前压/后撤） |
| 拖动轨迹（己方→敌方，向上） | 释放指向性技能（与横屏同一指令，只是构图纵向） |
| 双指点击（主视野） | 普通检定一键快掷 / 结束回合 |
| 长按 | 单位信息卡；骰子托盘长按=跳过演出 |
| 双指捏合 | 战场全局俯瞰 ↔ 跟随镜头，松手弹回 |
| 下滑（推进条） | 已过房间列表，快速回退 |

### 2.3 遭遇外（主屏 / 功能界面）

| 手势 | 作用 |
|---|---|
| 单点 | 全部导航与确认 |
| 长按 | 道具/图鉴/旗标详情 |
| 横滑 | 背包↔图鉴等同级页签 |
| 上滑（日志带/抽屉） | 展开半屏；下滑收起 |
| 点时间钟 | 时间边预告弹层 |

## 3. 手势冲突消解

1. **起点定语义**：拖动手势按按下点的语义分流——按在单位上=移动/轨迹，按在空白=镜头/滚动，按在列表=滚动；
2. **移动 vs 轨迹**：从己方单位起拖，轨迹终点落在敌方单位上=施法，落在空格=移动，抬手时预览确认，不即时生效；
3. **双指点击 vs 捏合**：以间距变化与时长区分——间距变化 <15pt 且持续 <300ms 为双指点击，否则进入缩放判定；双指点击不阻塞单指点按（两根手指先后落点间隔 >1 帧即不判为双指）；**不采用拇指双击**（遮挡视野、与快速连点选择易混淆，移动端误触率高）；
4. **缩放优先于旋转**：不提供旋转手势（与"模式非屏幕姿态"一致）；
5. 手势进行中被打断（来电/切后台）：按抬手于空位处理=取消，不产生半状态指令。

## 4. 首进教程与帮助页

三层结构，全部**可跳过、可重学、跳过不丢信息**：

| 层 | 触发 | 内容 | 形式 |
|---|---|---|---|
| 启动卡 | 首次启动（一次性） | 3 页核心手势：点按=选择、长按=详情、横滑=切换 | 全屏卡，右滑翻页，"跳过"常驻 |
| 情境教程 | 首次进入某情境（每类一次） | 首次检定=双指点击快掷；首次战斗=拖动移动+轨迹施法+双指点击结束回合；首次缩放可用=双指捏合 | 半透明遮罩+高亮目标区，非模态，点任意处继续 |
| 帮助页 | 常驻，主动进入 | 手势图鉴（本规范 §1~§2 全表）、情境教程重学入口 | 主屏"帮助"入口进入 |

- 触发记录写入存档（`global.tutorial.<id>`），不因重开重复打扰；
- 教程文本是内容包数据（可随战役换叙事包装），结构由框架恒定。

## 5. 主屏热点图（呈现方向，原型不实现）

① 主屏的视觉层是**一幅可交互的营地绘卷**（烬港夜景），功能入口以画面区域热点承载而非按钮列表：

| 画面区域 | 入口 |
|---|---|
| 潮汐塔（远景微光） | ② 战役入口 |
| 集市棚区 | ⑥ 背包图鉴 |
| 营火与同伴 | ⑦ 角色 |
| 告示板 | ⑤ 事件中心 |
| 残页堆 / 私藏抄本 | ⑧ 历史卷轴 |

规范：热点以微光呼吸提示（≤3 秒周期，不闪烁）；有未读状态的热点叠加角标；绘卷随纪元进度与旗标视觉变化（状态板的可视化，04 §4 ①）；**底部保留文字入口条作为无障碍与辨识度兜底**——热点图是皮肤，文字入口是骨架，两者功能等价。像素与分区规范属视觉稿阶段。

## 6. 热区铁律（沿用并冻结）

- 高频操作（动作轮盘、确认键、骰子托盘）收在**下半屏拇指弧区**；
- 顶部区域（状态栏带、推进条）只承担低频与"看"的信息；
- 可触目标最小 44×44pt；手势判定不依赖精确落点的，给最近目标吸附（≤12pt）。
