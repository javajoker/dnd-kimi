## 2. 剧情概要

你在烬港的潮声中醒来，怀里没有抄本。这座港城正在被“褪墨”抹去：先是地名，然后是一条街，然后是一个人的女儿。誊写庭想修复卷轴，断墨会想撕碎它，拾遗行会只想趁乱发财——三方都需要你手里那枚命骰。你一路追查褪墨的源头，进入已被撤销的旧城区，最终在潮汐塔顶面对一个问题：**这本书该修补、该焚毁，还是该由你重新写？**

## 3. 总体结构

```
序章「潮醒」──→ 幕一「褪色的街」──→ 幕二「三支笔」──→ 幕三「撤销区」──→ 终章「港口的最后一页」
 （强制竖屏）    （双模式可选）      （双模式可选）     （强制竖屏）      （双模式可选）
   教学 4 节点    调查+三方接触      三方支线择路        房间序列追忆      Boss+抉择+结局
```

### SL-2 幕二「三支笔」（双模式，12 节点）

四线择一为主，其余两线以“传闻”形式在事件中提及（状态板记录，多周目可补）。

```
【誊写庭链】
N2S-1 档案馆试炼 [检·历史/感知·中]
  ├─ 成功 → N2S-2；失败 → 罚做抄经役（耽误 1 格时间钟）→ N2S-2
N2S-2 修复仪式（护送战：保护缮写士完成局部重墨）
  └─→ N2S-3 金墨的代价 [选]
        ├─ 献出一段自己的记忆 → 时间钟 -2，旗标：空白记忆（个人向结局加成）
        └─ 拒绝 → 誊写庭声望 +1，时间钟 -1

【断墨会链】
N2U-1 黑羽集会 [检·潜行·中]
  ├─ 成功 → 旁听密谋；失败 → 暴露（战斗）→ 以武力赢得入场券
N2U-2 撕页行动（战斗 + [选]：是否撕掉税吏的命运页）
  ├─ 撕 → 断墨会声望 +2，旗标：撕页者（税吏从所有人记忆中消失）
  └─ 不撕 → 声望 +1，旗标：手下留情（税吏在终章提供关键证词）
N2U-3 自由的灰烬（演出：撕页的后果显现，时间钟 +1）

【拾遗行会链】
N2G-1 残篇拍卖 [检·交涉·中 或 支付金币]
  └─→ N2G-2 雾码头打捞（迷宫探索遭遇）
        ├─ [物·半页潮汐表] → 开启密道，直达沉书阁（额外战利品 + 织命者残简 ×1）
        └─ 无道具 → 绕行路线（多 2 场遭遇）
N2G-3 账本的真相（演出：行会早知褪墨将至；获得旗标：知情人）

【独狼捷径】（[声]或[检·难]进入）
N2L-1 独自调查 [检·调查·难]
  ├─ 成功 → 直抵真相（跳过一条支线的内容量，时间钟 -1，但无任何阵营声望）
  └─ 失败 → 被三方同时通缉（惩罚遭遇战后强制择一链，且声望 -1）

【收束】
N2-C 三方情报拼合（演出）→ 解锁幕三
  进入条件：任一链完成 N2x-3（或 N2L-1 成功）
```

### SL-3 幕三「撤销区」（强制竖屏 · 房间序列，7 节点）

叙事包装：被撤销的旧城区只剩残篇，只能一间房一间房地“回放”——这就是强制竖屏时间形态的理由。

```
N3-1 进入撤销区（模式锁定演出）→ 房间序列：
R1 褪色民居（拾取/检定房：被撤销者的生活痕迹）
R2 空教室（对话房：还记得自己名字的孩子 [检·安抚·中]，失败→孩子消散，旗标：未能挽留）
R3 墨魈巢穴（战斗房）
R4 分叉回廊（分支门：[物·黑羽令] 开左路捷径 / 右路两场战斗）
R5 守页人（Boss 战：誊写庭留下的自动缮写傀儡）
  └─→ N3-7 空白广场（终章入口；此处起解锁横屏）
```

### SL-4 终章「港口的最后一页」（双模式，4 节点）

```
N4-1 潮汐塔顶（最终 Boss 战：褪墨之潮的化身）
  └─→ N4-2 抉择 [选 + 声 + 物]
        ├─ 修补卷轴 → E1（需 墨守倾向 > 中线）
        ├─ 焚毁残卷 → E2（需 留白倾向 > 中线）
        ├─ 写新的一页 → E3（需 [物·织命者残简 ×4 集齐] 且 任一羁绊 ≥ 60）
        └─ 条件均不满足 / 时间钟已满 → E4 褪墨吞港
N4-3 结局演出（四分型）
N4-4 尾声与结算（写板：多周目继承项解锁）
```

## 9. 结局分型

| 结局 | 条件 | 内容 | 多周目钩子 |
|---|---|---|---|
| E1 重墨 | 墨守 > 中线 | 港城被重新书写，但献身者永为空白 | 解锁缮写圣城传闻 |
| E2 自由灰 | 留白 > 中线 | 烬港脱离织卷，自由而缓慢崩解 | 解锁裂页荒原传闻 |
| E3 新篇（隐藏） | 残简 ×4 + 羁绊 ≥60 | 白页者成为新执笔者 | 解锁“执笔者”开局身份 |
| E4 褪墨吞港 | 条件均不满足或时钟满 | 港城被撤销，你带着抄本残页离开 | 继承残页，二周目自带“追忆”视角 |

E4 是失败但非终局（白皮书 §5.2）：E4 通关仍写入全部收集与图鉴进度，且解锁多周目专属视角。
