# 数值定稿与 Boss 设计（烬港残页）

> 版本：v1.0
> 关联文档：`../framework/11-轻规则包-v1.md`（数值规则）、`02-战役书-烬港残页.md` §7/§11、数据：`campaign01/enemies.json` / `encounters.json`
> 范围：全部遭遇的难度目标、Boss 回合行为脚本、敌人数值定稿。定稿方法：**仿真实测驱动**——以 bot 胜率分布标定，不以拍脑袋填数。

---

## 1. 难度目标与标定方法

| 难度档 | 目标胜率（默认整备、无托管加成） | 体验定位 |
|---|---|---|
| 易 | 85~95% | 教学与叙事节奏点 |
| 中 | 70~80% | 主线标准张力 |
| 难 | 50~65% | 惩罚路与终章，可败但有戏 |

标定方法：`tools/winrate.gd` 对每场遭遇以默认队伍跑 200 局 bot 战斗，胜率落入目标区间即定稿；超出则调敌人 HP/攻击/数量（不改规则包）。

## 2. Boss 回合行为脚本

敌人条目新增 `behavior`（回合行为脚本，数据驱动）：

```json
"behavior": [
  { "every_n_rounds": 2, "skill": "ink_surge" },
  { "when_hp_below": 0.5, "once": true, "skill": "call_imps" }
]
```

| 字段 | 含义 |
|---|---|
| `every_n_rounds` | 每 N 回合释放该技能（替代普攻） |
| `when_hp_below` + `once` | 血量阈值触发一次（转阶段） |
| `skill` | 引用敌人自带技能（AoE 带 save 声明，11 §5.1） |

脚本按序求值，无命中即普攻。行为脚本产出全部进事件流（`battle.skill`，含 save 明细）。

## 3. Boss 设计稿

### 3.1 守页人（R5，难）

- 定位：誊写庭的自动缮写傀儡——秩序的执行者；
- `seal_shock` 封印冲击：每 2 回合 AoE（敏豁免 DC 12，半伤 1d6+2）；
- 转阶段：HP<50% 时一次「重写守则」——本场自身攻击 +1（事件流可溯）。

### 3.2 墨潮化身（N4-1，难）

- 定位：褪墨之潮的化身；
- `tide_sweep` 墨潮席卷：每 2 回合 AoE（敏豁免 DC 13，半伤 1d6+2）；
- `call_imps` 召唤：HP<50% 时一次召唤墨魈幼体 ×2（受同屏 ≤8 约束校验）；
- 手下留情旗标 → `enemy_weaken` 攻击 -2（tech/02 §6，已有）。

## 4. 敌人数值表（定稿）

以 §1 仿真标定后的终值为准，写 `campaign01/enemies.json` 并移除"数值待定稿"标注；每次后续调整需重跑 winrate 并留记录（变更记录）。

## 5. 成长与消耗品校核

- 序章+幕一 ~幕三主线经验总量 vs 300/700/1200 门槛表校核：通关应达 Lv3 左右（含一条支线复玩达 Lv4，战役书 §1）；实测（winrate 标定轮）：誊写庭链 810 / 断墨会链 1110 / 拾遗行会链 1040，均落 Lv3 ✓；
- 独狼链总计 1290 → Lv4——属"高风险高回报"设计的预期上限，保留（2026-11-09 验收裁决）；
- 补给药水/墨核投放量 vs 难度目标校核（11 §9 投放节奏）：标定按"默认整备无道具"从严，药水即玩家容错余量。
