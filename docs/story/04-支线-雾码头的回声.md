# 支线 · 雾码头的回声（arc_tide）· 设计说明

> 版本：v1.0（M4 内容扩充）
> 文档依据：tech/02 §2.6（graft 支线挂接声明块）、§12 V14（graft 校验）、白皮书 §10.4（内容轨：
> 支线只动 packs/ 数据 + core 通用挂接能力）、08 文档（分支模型：支线收束回主线）。
> 数据包：`game/packs/arc_tide/`（编写源即本文件随附数据表，双副本纪律同 campaign01）。

## 1. 一句话

在自由市广场买下那半页潮汐表的人，会在某个起雾的夜里听见雾码头的打捞铃——拾起一段
被誊写庭从名册上划去的人生。

## 2. 挂接方式（graft，不动主线数据）

```json
"graft": {
  "into": "campaign01",
  "node": "N1-1",
  "edge": { "type": "item", "item": "half_tide_table", "label": "循着潮汐表的指引",
    "to": "T-1", "requires": { "flag.done": false } }
```

- **触发**：持有「半页潮汐表」（campaign01 N1-1 商店投放，战役书 §8）时，N1-1 多出一条
  道具边「循着潮汐表的指引」；未持道具不显形（tech/02 §4.3 无 fallback 即隐）；
  `requires: flag.done=false` 使支线完成后入口隐去（边条件解析到支线命名空间，§2.6）；
  包缺失 / 权利门槛未点亮 = 不注入，主线逐字节不变；
- **收束**：支线终点 T-4 边指回宿主节点 N1-1（回主线 Hub，可继续主线）；
- **权利**：`monetization.strategies = ["free"]`，不声明 entitlement.requires —— 随本体免费。

## 3. 节点弧（4 节点，节点预算 6）

| 节点 | 类型 | 内容 |
|---|---|---|
| T-1 | check | **雾码头夜探**：perception 检定·中。成功 → 循铃而去（T-2）；失败 → 同样抵达 T-2，但惊动了雾里的东西（`clock +1`，失败即分支的代价汇合型式 B，差异体现在成败效果） |
| T-2 | battle | **打捞战**：捞起沉箱的瞬间遭伏击——墨魈 ×1 + 墨魈幼体 ×2（复用 campaign01 enemies.json 墨魈系，支线引用宿主资源表，tech/02 §2.6）。胜利后唯一出边 → T-3 |
| T-3 | scene | **被撤销者名录·残页**：on_enter 结算——图鉴条目 `revoked_registry_tide`（lore 效果，入 global.lore）+ 拾遗行会声望 +1（rep.salvage）+ 经验 +40（xp 汇入成长，tech/04 §8 规则1） |
| T-4 | scene | **收束**：on_enter 写 `arc_tide.done`；唯一出边 → N1-1（回主线） |

旗标台账：`done`（writers: T-4；readers: 历史卷轴 / 后续支线联动预留）——不进入 campaign01
结局条件，**主线四结局分布不受影响**（结局表求值只读宿主 endings，支线不并入 endings，tech/02 §2.6）。

## 4. 与主线的接口面

- **读**：`item.half_tide_table`（宿主道具，graft 边显形条件）；
- **写**：`arc_tide.*` 命名空间旗标（07 §3：仅本包可写）；`global.lore` / `global.rep.salvage` /
  `global.growth.*`（全局白名单，任何包可写）；`global.doom_clock` 仅 T-1 失败路 +1（V5 合并视图
  时钟代数和宿主 5 + 支线 1 = 6 ≤ 10，有界）；
- **不写**：主线任何旗标、结局条件、节点数据（graft 纯注入，宿主包零改动）。

## 5. 校验与仿真口径

- packlint：`lint_grafted`（tech/02 §12 V14）——V1~V3 图遍历在合并视图跑（T-1~T-4 经注入边
  可达宿主结局），V4/V6~V9/V11~V13 按本包口径，资源引用（墨魈系敌人、player_blank、
  half_tide_table）在合并视图解析；
- 仿真：bot 持潮汐表时注入边可见，支线弧走通后回 N1-1；结局分布断言四结局全集保持
  （arc 不影响主线结局，见 tests/run.gd test_arc_tide）。
