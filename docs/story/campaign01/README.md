## 转写决策记录

- **派生节点**：设计稿中"失败路 / 密道 / 绕行"等依附于主节点的分支，以主编号加小写后缀落位（`N0-3a/b`、`N1-2b`、`N2U-1b`、`N2G-2b/2c`、`N2L-1b`、`R4-r`、`N4-1b`）。节点预算按主编号计逻辑节点，派生节点不另占预算。
- **结局节点**：设计稿的 N4-3（结局演出）与 N4-4（尾声结算）不单独成节点，合并进 `type: "ending"` 的 E1~E4——结局节点的固有职责即演出 + 结算 + 多周目写板。
- **N1-7 的入口**：墨雨夜袭在事件层是时间边（`events.json` 的 `ink_rain_raid`，时钟到 2 格触发）；图层三个接触节点（N1-4/5/6）按战役书汇流至 N1-7。
- **R2 残简**：设计稿"R2 隐藏 ×1"落在安抚检定成功路（成功即发现孩子的藏身细节）。
- **文本**：首版内嵌中文摘要，`lore.json` 以 `text_ref` 预留文本抽取位。
- **倾向投放补全（TP1 转写补全）**：战役书 §9 结局条件要求墨守/留白过中线，但初版节点图无 alignment 投放点。按 §9 设计意图补：誊写庭链（N2S-3 两条选择边）各 +10（墨守）、断墨会链（N2U-2 两条选择边）各 -10（留白）；拾遗行会链与独狼链不动倾向（对应 E4 路径）。
- **潮汐表投放补全（TP1 转写补全）**：战役书 §8 投放点含"N1-1 商店"，初版节点图缺落位。于 N1-1 hub 增"购买半页潮汐表"选择边（give_item，价格占位待定稿）；"N1-2 隐藏拾取"第二投放点留待探索遭遇细化（开放项，TP1 验收裁决 4 维持）。
- **独狼入口补全（TP1 验收裁决 1）**：图层原强制经过一个三方接触节点（声望 +1），N1-8 独狼门槛（三方 ≤0）永不满足。于 N1-3 增"婉拒所有邀约"选择边直达 N1-8（无效果、声望保持 0），战役书 §4 SL-1 图同步补行。
- **羁绊投放补全（TP1 验收裁决 2）**：E3 需任一羁绊 ≥60（战役书 §9），初版无 bond 写入点。投放：N1-7 战后边 +10、N2S-3 两条边各 +15、N2U-3/N2G-3 on_enter 各 +15、R2 安抚成功 +20；同伴 id 暂用 `kelan`（占位，待 TP 同伴系统定稿）。单周目图内上限 45，E3 的 60 门槛由多周目继承（上周目图内所得）达成。
- **遭遇补登记（TP1 验收裁决 3）**：N2G-2c（绕行，maze/inherit/medium/4）与 R1（拾取检定房，maze/forced_time/easy/2）补入 encounters.json，节点侧补 encounter 关联；遭遇总数 14 → 16。
- **战斗数值入表（M2 路径第一步）**：characters/skills/enemies 三表新增，数值逐键转写自技术原型 TP2 引导脚本（与 11 文档一致，转写搬运非再创作）；引导层（main.gd）改为 pack 数据驱动组装战斗定义，同种子同指令事件流与旧硬编码逐字节一致作为"无再创作"硬证明。hp/ac 公式取可复现现值的简式（如 `10 + 2*might`=14），规则包求值器（tech/04 §2）同步落位。
- **字段扩展登记（M2）**：encounters.json 的 `party` / `enemies` / `party_advantage` / `loot` / `xp` 与 characters.json 的 `basic_attack` 均为可选扩展字段，已同步登记 tech/02 §6 与 tech/04 §2（§11：新增字段一律可选）。`party_advantage` 即 11 §3.1"见证撤销 → 首回合全队优势"的内容包声明落位。
- **墨盾格挡取值（M2 裁决）**：按 11 §3.1 与原型硬编码，效果仅"持续期间攻击者劣势"，**不含 AC+2**；任务描述中的"AC+2"与文档不符，未落位，待裁决后再以一行数据追加（runtime statuses 已支持 `ac_bonus`）。
- **heal_potion use 块（M2 裁决）**：采用扁平键 `{timing, heal, consume}`（与运行时一致），tech/04 §4 示例的 `effect` 嵌套形态待 §5 效果系统运行时接入后统一（规范已补落位注记）。
- **价格占位（M2）**：N1-1 商店半页潮汐表价格占位 15，落 `items.json` 的 `price` 可选字段与节点边文案；heal_potion 投放点为序章带入 ×2（战役书 §4），N1-1 商店引用记于 `source`，不新增购买边（商店货单属战役书内容，不再创作）。
- **其余战斗遭遇敌人未定稿（M2 留白）**：仅 N1-7 登记 `party`/`enemies` 实例；R3/R5/N4-1 等战斗遭遇的敌人阵容待内容定稿，V11 仅校验已声明引用的闭环。
