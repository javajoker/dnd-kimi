# 竞技场连战（arena）· 概念设计

> 版本：v0.1（M3 验证切片）
> 文档依据：白皮书 §10.2（子游戏 = 复用遭遇状态机、替换规则参数与表现包装的内容包）、
> 04 文档 §6（进场/离场必经 ⑨ 结算界面；入口挂 ② 战役入口区，不新增全局导航项）、
> tech/02 §2（manifest `pack_type: "subgame"` + `subgame` 变体声明）、11 §7.1（HP 跨遭遇持久化）。
> 数据包：`pack/`（编写源，同步副本 `game/packs/arena/`，双副本纪律同 campaign01）。

## 1. 一句话

烬港地下誊写场的连战擂台：三场递增难度的遭遇连续开打，场间无休整，打到哪里算哪里——**失败即分支**的竞技场形态。

## 2. 玩法结构

```
进场（A-0 演出）→ 战 1 幼体群（易）→ 战 2 墨魈（中）→ 战 3 守页人精英（难）→ 结算（A-END）
                     ↘ 见好就收 → 结算      ↘ 见好就收 → 结算
                     ↘ 败北 → 按已完成场次结算（任意场次）
```

- 连战 3 场，难度 易 → 中 → 难（轻规则三档，11 §3）；
- 每场胜利后玩家二选一：**乘胜追击**（下一场，无休整、HP 不恢复）或 **见好就收**（按已完成场次结算）；
- 任一场败北 = 本次连战结束，按已完成场次结算（失败即分支，白皮书 §5.2 的竞技场形态）；
- HP 跨场持久（11 §7.1）：`<ns>.hp.<char_id>` 簿记，场间不恢复——这是"连战无休整"的规则落点；
- 进场一次整备（09 §9.1），连战中途不再整备；次数制技能按 11 §8 随每场遭遇组装重置。

## 3. 奖励（写状态板是硬要求，04 §6）

| 时机 | 奖励 | 落点 |
|---|---|---|
| 每场胜利 | 经验（遭遇 xp：50 / 80 / 120） | `xp.gain` 事件（溯源 pack=arena） |
| 每场胜利 | 金币（20 / 30 / 50，manifest `subgame.gold_reward` 声明） | `<ns>.gold` 计数簿记（07 §2 约束3，同 campaign01.gold 先例） |
| 全胜追加 | 墨核 ×1（A-3 胜利边 `give_item` 效果） | `global.inv`（背包互通） |
| 每次连战结束 | 战绩：累计胜场 / 最佳连战 | `<ns>.wins` / `<ns>.best` 簿记键（manifest `subgame.stat_keys` 声明） |
| 每场胜利 | 场次旗标 stage1/2/3_cleared、全胜 flawless | `<ns>.*` 旗标（flags.json 台账，V4 闭环） |

金币与战绩为计数/簿记键，不进 flags.json 台账（同 campaign01.gold / xp_total 先例）。

## 4. 门槛与互通（白皮书 §10.2：通过状态板与主线互通）

- **读 global**：建议等级 Lv2+（manifest `recommended_level: [2, 4]`，入口卡呈现，不硬锁）；
- **写 global**：墨核进 `global.inv`（主线可见可用）；经验进事件流（成长结算归各战役元循环，本子游戏不接入加点）；
- **写 `<ns>`**：金币 / 战绩 / 场次旗标均在 `arena.*` 命名空间（07 §3 命名空间权限，跨包写禁止）。

## 5. 规则变体声明（tech/02 §2）

- 复用轻规则包 **light_v1**（`rule_pack: {"id": "light", "min_version": 1}`），不新增规则参数；
- 变体声明：`subgame.rules_override = { "arena_mode": true }`——仅表现层语义（连战无休整间隔、结算呈现连战战绩），**渲染层对规则档位无感**（05 文档铁律），rules_override 不进 EncounterSM 数值路径；
- 模式声明：`presentation.mode = "choice"`（双模式可选，tech/02 §2.1）：随玩家战役模式或入口选择，入口卡提供竖屏/横屏两个参战按钮。

## 6. 界面与框架承诺（04 §6）

- 入口：② 战役入口区"特殊战役书卡"（`pack_type=subgame` 即入列，数据驱动，不写死 arena）；
- 内部：演出节点复用双壳故事态；战斗复用 EncounterSM ×3（一核两壳，09 §8）；
- 进场/离场必经 ⑨ 结算界面：汇总区间逐项念出（经验/金币/墨核/战绩），出口 = 回主屏 / 历史卷轴；
- 不新增全局导航项，九类界面闭环不被破坏（04 §5）。

## 7. 阵容与敌人（数值均在 light_v1 范围内）

- 队伍：白页者 + 珂兰 + 老费（自 campaign01 数据转写，后续可独立调整——子游戏可独立发布更新）；
- 战 1：墨魈幼体 ×3（复用）；战 2：墨魈 + 幼体 ×2（复用）；战 3：**守页人精英**（新增）+ 幼体 ×2——
  精英带范围技能「封印冲击」（豁免 DC12/半伤，11 §5.1 落位）。
