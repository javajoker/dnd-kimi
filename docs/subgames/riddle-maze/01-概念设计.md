# 谜回廊（riddle_maze）· 概念设计

> 版本：v1.0（M4 内容扩充，第二子游戏）
> 文档依据：白皮书 §10.2（子游戏 = 复用遭遇状态机 + 替换规则参数与表现包装）、04 §6（进出场
> 必经 ⑨ 结算；入口挂 ② 战役入口区）、tech/02 §2.5（subgame 变体块）/§6（maze 节拍，
> retry_on_fail/hint 解谜房语义）、11 §2/§3（检定公式）。
> 数据包：`pack/`（编写源，同步副本 `game/packs/riddle_maze/`，双副本纪律同 campaign01/arena）。

## 1. 一句话

誊写场地下还有一条更老的回廊：三间以谜题代锁的静室——**不动刀兵，只动脑子**；
答错了，回廊会给你提示，陪你再想一次。

## 2. 玩法结构（纯解谜房间序列，零战斗）

```
进场（R-0 演出）→ 静室一（R-1 智检定·中）→ 静室二（R-2 拾取谜面残页 + 智检定·中）
                → 静室三（R-3 智检定·难）→ 结算（R-END）
```

- 复用 **MazeRunner 探索序列**（tech/02 §6 maze）承载房间内容：检定房 + 拾取房的节拍序列，
  **零战斗**——不声明任何 battle 节点/遭遇敌人；
- **失败给提示重来、不进死路**：全部检定拍声明 `retry_on_fail: true` + `hint`（tech/02 §6）——
  检定失败不推进节拍、不吃失败效果，呈现提示文案原地重试；
- 检定均为**智系技能**（investigation/history/perception，11 §2 智属性衍生），修正 = 玩家属性+熟练；
- 中途 ☰ 离场续打由 MazeRunner 节拍进度簿记（`<ns>.maze.<enc>.idx`，07 §4.2）天然支持。

## 4. 门槛与商业化（tech/02 §2.2/§2.3）

- **entitlement 缺省 = 随本体免费**；`monetization.strategies = ["free"]`（V9 一致性：free 不得声明 requires）；
- 与主线互通：经验汇入成长、金币/图鉴/道具经全局键互通；不读不写主线旗标。

## 5. 规则变体声明（tech/02 §2.5）

- 复用轻规则包 light_v1，无规则参数改动；`rules_override = { "puzzle_mode": true }`——
  仅表现层语义（无战斗、结算呈现解谜战绩），渲染层对规则档位无感（05 铁律）；
- `presentation.mode = "choice"`：入口卡双形态参战按钮（04 §6 数据驱动入列）。

## 6. 界面与框架承诺（04 §6）

- 入口：② 战役入口区子游戏卡（数据驱动，与 arena 同通道）；
- 内部：演出/解谜房间复用双壳故事态 + 迷宫节拍呈现；进出场必经 ⑨ 结算（汇总：经验/金币/图鉴/战绩）；
- core 复用：StoryGraph 走节点图 + MazeRunner 走节拍，**零战斗路径不实例化 EncounterSM**；
  本子游戏落位未新增任何 core 类型（M4 core 改动只有 graft 通用能力与 maze retry 字段，与本子游戏解耦）。
